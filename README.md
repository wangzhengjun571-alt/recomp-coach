# recomp-coach

一个 Claude **Agent Skill**，将 Claude 转变为一个确定性状态机教练，管理一套 **5:2 轻断食 × 碳水循环** 身体重组方案。**通用设计** — 适用于任何健康成年人。

## 运作方式

### 首次使用：设定个人资料
用户提供 6 项基本数据（性别、身高、体重、体脂率、目标体脂率、年龄），引擎基于 **Mifflin-St Jeor 公式** 计算 BMR/TDEE，基于 **Morton et al. 蛋白质天花板** 设定蛋白质锚点，自动生成个性化三种日型的宏量营养素目标。

### 每日日志：三步流水线
每次用户提交训练/饮食日志时，skill 严格按以下顺序执行：

1. **解析（Parse）** — 将日志提取为 JSON，与 `schema/daily_log.schema.json` 校验。
2. **诊断（Diagnose）** — 找出与当天目标相比**最大的单一差距**（通常是蛋白质不足或碳水时机错误），量化到克数和百分比。
3. **调整（Adjust）** — 仅当触发条件满足时，给出**至多一条**基于证据的调整建议。所有调整按比例缩放（非绝对数值），匹配用户当前方案。

### 定期回顾
每 4 周一次结构化回顾；安全警戒线（体重下降过快、持续头晕、强迫性节食、力量退步+疲劳 → 建议暂停并咨询专业人士）。**瘦体重和运动表现优先于体重秤数字。**

## 饮食方案架构：三种日型（自动计算）

| 日型 | 场景 | 热量 | 蛋白质 | 碳水 | 脂肪 |
|---|---|---|---|---|---|
| 🔴 高碳日 | 练腿 / 大重量推 | Training TDEE + 150 | 体重×2.2g | 热量填充 | 体重×0.9g |
| 🟡 中碳日 | 拉类 / 容量训练 | Training TDEE − 250 | 体重×2.2g | 热量填充 | 体重×1.0g |
| 🟢 断食日 | 完全休息 | ~BMR×0.35 | LBM×1.6g | 极低 | 体重×0.25g |

**硬性规则：** 🔴 高碳仅在两个最大肌群训练日使用；🟢 断食日绝不训练。

## 安装方式（Claude Code / Claude Desktop）

```bash
git clone https://github.com/wangzhengjun571-alt/recomp-coach.git ~/.claude/skills/recomp-coach
```

将 `recomp-coach/` 放入 Claude 的 skills 发现路径。Claude 加载 `SKILL.md`，其中的 `description` 字段控制自动触发条件。

## 使用示例

```
用户：设定资料：男，179 cm，68 kg，体脂 20%，目标 14%，28 岁
→ Coach 输出个性化三种日型方案

用户：周一练腿，吃了 2500 卡 130g 蛋白 300g 碳水 70g 脂肪，体重 68，腰围 81.5，睡 6h
→ Coach 三步流水线：解析 JSON → 诊断碳水缺口 → 训练前碳水翻倍
```
